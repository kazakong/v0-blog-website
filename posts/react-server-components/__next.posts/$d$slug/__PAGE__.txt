8:T98f,<h1>Understanding React Server Components</h1>
<p>React Server Components (RSC) represent a fundamental shift in how we think about React applications. They allow components to run on the server, reducing the JavaScript sent to the client.</p>
<h2>What Are Server Components?</h2>
<p>Server Components are React components that:</p>
<ul>
<li>Run exclusively on the server</li>
<li>Have zero impact on bundle size</li>
<li>Can directly access server resources (databases, file system)</li>
<li>Cannot use hooks or browser APIs</li>
</ul>
<h2>Server vs Client Components</h2>
<h3>Server Components (default in Next.js App Router)</h3>
<pre><code class="language-tsx">// app/posts/page.tsx
async function PostsPage() {
  const posts = await db.posts.findMany();
  
  return (
    &#x3C;ul>
      {posts.map(post => (
        &#x3C;li key={post.id}>{post.title}&#x3C;/li>
      ))}
    &#x3C;/ul>
  );
}
</code></pre>
<h3>Client Components</h3>
<pre><code class="language-tsx">'use client'

import { useState } from 'react';

export function Counter() {
  const [count, setCount] = useState(0);
  
  return (
    &#x3C;button onClick={() => setCount(c => c + 1)}>
      Count: {count}
    &#x3C;/button>
  );
}
</code></pre>
<h2>Benefits</h2>
<h3>Reduced Bundle Size</h3>
<p>Server Components don't add to your JavaScript bundle. Large dependencies stay on the server.</p>
<h3>Direct Data Access</h3>
<p>No need for API routes—fetch data directly in your components:</p>
<pre><code class="language-tsx">async function UserProfile({ userId }) {
  const user = await prisma.user.findUnique({
    where: { id: userId }
  });
  
  return &#x3C;ProfileCard user={user} />;
}
</code></pre>
<h3>Automatic Code Splitting</h3>
<p>The framework handles which code goes to the client and which stays on the server.</p>
<h2>Patterns</h2>
<h3>Composing Server and Client Components</h3>
<pre><code class="language-tsx">// Server Component
import { ClientButton } from './ClientButton';

async function ServerPage() {
  const data = await fetchData();
  
  return (
    &#x3C;div>
      &#x3C;h1>{data.title}&#x3C;/h1>
      &#x3C;ClientButton /> {/* Interactive client component */}
    &#x3C;/div>
  );
}
</code></pre>
<h2>Conclusion</h2>
<p>Server Components are a powerful tool for building performant React applications. They reduce bundle sizes, simplify data fetching, and create a better developer experience.</p>
